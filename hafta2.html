CSS Seçiciler

Grup ve Hiyerarşik Seçiciler

Grup seçici birden fazla öğeye aynı stili uygulamanızı sağlar. Öğeler virgülle ayrılır.

/* Grup seçici — en az 1 adet gerekli */ h1, h2, h3 { margin-bottom: 10px; line-height: 1.3; }

Hiyerarşik (descendant) seçici bir öğenin içindeki belirli torun öğeleri seçer; seçiciler boşlukla ayrılır.

/* Hiyerarşik seçici #1 */ .h2-icerik p { font-size: 16px; color: #c9d1d9; line-height: 1.8; text-align: justify; } /* Hiyerarşik seçici #2 */ .h2-sidebar h3 { font-size: 1.05em; color: #58a6ff; }
Yatay Menü

display: inline-block ile Yatay Navigasyon

Liste öğeleri varsayılan olarak display: block davranışıyla alt alta dizilir. display: inline-block atayarak bunları yan yana getirebilirsiniz.

nav ul li { display: inline-block; /* yan yana */ margin: 0 2px; } nav ul li a { display: block; padding: 10px 16px; color: #c9d1d9; text-decoration: none; border-radius: 6px; transition: color 0.2s, background-color 0.2s; } nav ul li a:hover { color: #58a6ff; /* hover rengi */ background-color: rgba(88,166,255,0.1); }
Metin Biçimlendirme

font-size · color · line-height · text-align

CSS metin özellikleri okunabilirliği doğrudan etkiler. Aşağıdaki dört temel özellik her web sayfasında mutlaka kullanılır.

p { font-size: 16px; /* karakter boyutu */ color: #c9d1d9; /* metin rengi */ line-height: 1.8; /* satır aralığı */ text-align: justify; /* metin hizalama */ }

font-size: piksel, em veya rem cinsinden belirtilebilir.
line-height: katsayı (ör. 1.8) veya piksel olabilir.
text-align: left · right · center · justify değerlerini alır.

İki Sütunlu Düzen

Bu sayfa display: inline-block ile iki sütuna bölünmüştür. Sol sütun %65, sağ sütun %31 genişliğindedir.

.icerik { display: inline-block; vertical-align: top; width: 65%; } .sidebar { display: inline-block; vertical-align: top; width: 31%; margin-left: 4%; }
