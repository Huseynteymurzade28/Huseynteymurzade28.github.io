Flexbox ve Kart Düzeni

display: flex ile oluşturulan interaktif kart düzenleri. Kartların üzerine gelin — animasyonları inceleyin.

01

justify-content: space-between  ·  align-items: stretch

Kartlar yatayda eşit boşlukla dağıtılır; tüm kartlar aynı yüksekliğe getirilir. Kartların üzerine gelin.

display: flex; justify-content: space-between; align-items: stretch; gap: 16px;

⚡ HTML5

Web sayfalarının iskeletini oluşturan işaretleme dilidir. Tarayıcının anlayacağı yapıyı tanımlar.

Yapı

🎨 CSS3

Sayfaların görsel tasarımını ve düzenini belirleyen stil dilidir. Flexbox bu hafta odağımız.

Stil

✨ JavaScript

Sayfaya etkileşim ve davranış katan, tarayıcıda çalışan programlama dilidir.

Davranış
02

flex-wrap: wrap

Kart sayısı satıra sığmadığında alt satıra kayar. Pencereyi küçültürken davranışı gözlemleyin.

display: flex; flex-wrap: wrap; gap: 14px; align-items: flex-start;

🔀 Git

Versiyon kontrol sistemi. Ekip çalışmasının temel taşıdır.

🐧 Linux

Açık kaynak işletim sistemi. Sunucularda yaygın olarak kullanılır.

🐋 Docker

Uygulamaları konteynerlerle izole eden platform.

💻 VS Code

Microsoft'un açık kaynaklı kod editörü.

🌿 Neovim

Terminal tabanlı güçlü Vim editörü.

🐙 GitHub

Git depolarını barındıran iş birliği platformu.

03

justify-content: center

Kartlar yatay eksende ortalanır. Yan boşluklar otomatik olarak eşitlenir.

display: flex; justify-content: center; flex-wrap: wrap; gap: 16px;

🐍 Python

Basit sözdizimi ile hızlı prototipleme için idealdir.

🦀 Rust

Bellek güvenli sistem dili. Yüksek performans sunar.

🐹 Go

Eşzamanlı sistemler için Google tarafından tasarlandı.

04

flex-direction: column

İki bağımsız sütun, her biri dikey yönde sıralanmıştır. Dış kapsayıcı row, iç kolonlar column.

display: flex; flex-direction: column; gap: 12px;

🖥️ Ön Uç

HTML, CSS, JavaScript ile kullanıcı arayüzü.

⚙️ Çerçeveler

React, Vue, Svelte gibi UI kütüphaneleri.

🎨 Stil Araçları

Tailwind, Bootstrap, Sass vb.

🗄️ Arka Uç

Sunucu tarafı mantığı, veritabanı, API.

💾 Veritabanları

PostgreSQL, SQLite, MongoDB vb.

☁️ Bulut & DevOps

Docker, CI/CD, cloud platformlar.

05

flex-grow

Orta kart flex-grow: 2 aldığından, diğer iki karta kıyasla iki kat daha fazla alan kaplar.

flex-grow: 1  |  flex-grow: 2  |  flex-grow: 1

◼ Küçük

flex-grow: 1

◼ Büyük (2×)

flex-grow: 2

Kalan alanın yarısını alır — yan kartların iki katı genişlik.

◼ Küçük

flex-grow: 1

📖

Flexbox Temel Özellikleri

Kart düzenlerinde sık kullanılan CSS Flexbox özellikleri.

display: flex

Elemanı flex kapsayıcı yapar; alt öğeler flex item olur.

justify-content

Ana eksen hizalaması: flex-start, center, space-between, space-around…

align-items

Çapraz eksen hizalaması: flex-start, center, stretch, flex-end…

flex-wrap

Sığmayan öğelerin alt satıra geçip geçmeyeceğini belirler.

flex-direction

Ana eksen yönü: row (yatay) veya column (dikey).

flex-grow

Kalan alanın paylaşım katsayısı.

gap

Flex öğeleri arası boşluk. row-gap ve column-gap kısayolu.

flex: 1

flex-grow:1, flex-shrink:1, flex-basis:0 kısayolu.
