01 — selected work

Things that run in a terminal

Most of these started as something I needed myself and grew from there. All of them are on GitHub, source included.

featured

flerp

23

A ratatui workspace for exploring and analysing files without leaving the command line. Live search, keyword extraction, repeated-line detection — and it reads PDFs page by page, text and embedded images included.

Rust open repo ↗

Yoinky

8

A Linux system monitor. Live CPU, memory and network sparklines, a per-core histogram and Overview · Processes · Devices · I/O tabs — a real dashboard rather than a static snapshot.

Rust open repo ↗

memflex

6

My own dynamic memory manager built on sbrk. First-fit, best-fit and worst-fit strategies, fragmentation handling, and a benchmark suite that puts them side by side.

C open repo ↗

Kizamu

4

A terminal typing trainer written in Zig. The name comes from 刻む — to carve. Measures WPM and accuracy behind a clean interface, aiming for zero dependencies.

Zig open repo ↗

cbbox

5

A CHIP-8 interpreter rendering through SDL2. I wrote it to build the fundamentals of emulation end to end — opcode decoding, timers, memory map.

Rust open repo ↗

klavrasa

3

A piano-roll visualiser that renders MIDI files as falling notes. The MIDI parser is written from scratch and audio is synthesised in real time from sine waves.

Odin open repo ↗
