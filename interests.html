Rust
My main language. Memory safety without giving up performance — most of my terminal tools are written in it.

For simplicity and compile-time control. My go-to for interpreter and TUI experiments.

Memory management, operating system concepts and embedded work — whenever I need the lowest layer.
Go
Concurrency and networked applications. When something needs to work quickly and ship easily.
Odin
Graphics and games. Together with Raylib, whenever I want to draw something to a screen.

Rapid prototyping, automation, and data or machine learning work.
