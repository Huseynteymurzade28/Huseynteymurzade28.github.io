projects

Things I've built

Most of these came out of my own needs: work without leaving the terminal, stay fast, install in one command. Everything is open source — each title links straight to its repository.

01 — terminal & tui

Terminal tools

featured

flerp

23

A full-screen ratatui workspace for exploring and analysing local files without leaving the command line. Live search, file statistics, keyword extraction and repeated-line detection; it reads every page of a PDF and renders the embedded images as real pixels in terminals that support a graphics protocol.

Rust open repo ↗

Yoinky

8

A Linux system monitor. Continuously updating sparklines for CPU, memory and network, a per-core histogram and a tabbed workspace that pulls load, uptime, storage pressure and throughput onto one screen.

Rust open repo ↗

meloic

5

A terminal music player. Browse your collection, play and pause from the keyboard, all behind a lightweight and fast interface.

Rust open repo ↗

Kizamu

4

A terminal typing trainer written in Zig — 刻む, "to carve". It measures words per minute and accuracy, and keeps the practice inside the terminal.

Zig open repo ↗

bytesizepet

4

A virtual pet living entirely in your TTY. Day/night sky, real-world weather data and drifting particles; the pet persists between runs and keeps ageing while you're away.

Go open repo ↗

cosmocli

3

A space explorer for the terminal: planets, stars, the ISS, rocket launches, the Moon, asteroids and every known exoplanet — all in a keyboard-driven interface.

Rust open repo ↗

chokuto

3

A LAN chat and file-sharing tool that runs entirely in the terminal. No internet, no accounts, no config files — launch the server on one machine and connect from any other on the same network.

Go open repo ↗

pokeductor

A Pokédex that fetches PokeAPI data asynchronously, parses branching evolution trees and renders pixel-art sprites right in the terminal.

Rust open repo ↗

digiductor

3

The Digimon side of the same idea: search and filter from the API, inspect detailed attributes, and visualise complex branched evolution trees in the terminal.

Rust open repo ↗

fasta-tui

A terminal viewer for FASTA sequences. It shows DNA, RNA and proteins through an interactive 3D Braille double helix, with real-time codon highlighting and GC content tracking.

02 — systems & low level

Where I wrote the plumbing myself

memflex

6

A user-space dynamic memory manager built on sbrk: my_malloc, my_free, my_calloc. Includes first-fit, best-fit and worst-fit strategies, fragmentation handling and a comparative benchmark suite.

C open repo ↗

cbbox

5

A CHIP-8 interpreter that draws through SDL2. The core instruction set, timers and memory map are built from scratch — this was my way into emulator development.

Rust open repo ↗

liszig

3

A minimal, modular Lisp interpreter written in Zig. Lexer, a parser that builds an AST from tagged unions, and an evaluator — with both a REPL and script execution.

Zig open repo ↗

Diptych

3

A file manager built from scratch with Rust and GTK4. The name refers to a two-panelled artwork, which mirrors the dual-pane and inspector layout. Runs on Linux and compiles for Windows and macOS.

Rust open repo ↗

artbucket

2

A procedural terrain texture generator with a live-preview desktop GUI and a batch-friendly CLI. Perlin and Worley noise, fractal octave stacking, colour ramps, hillshading, normal-map baking and even the PNG encoder are all implemented by hand.

Rust open repo ↗
